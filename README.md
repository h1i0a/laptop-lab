# Laptop Lab

Static laptop comparison website for GitHub Pages. No install, backend or build required.

Publish main / (root) in Settings → Pages. All app files are at repository root.

- Compare up to four devices with SAR prices, editable availability and weighted scores.
- The catalog groups current options, historical offers and wider comparison records. Current options can be compared even when a physical measurement or exact regional detail is missing; unknown values remain marked. Historical offers are excluded from purchase ranking.
- Priority cards show the available result for one eligible laptop and name a leader when two or more can be compared. Sound uses personal listening ratings.
- Physical design inspector with closed sides, front/rear, lid, display lip, deck and touchpad. Calibrate against a 100 mm ruler for 1:1 physical display on your current screen. Published or labelled same-platform dimensions establish scale. Matching supplied photos inform the MSI, HONOR, Yoga Pro 7, HP OmniBook Ultra 14, TECNO MegaBook S14 and Yoga Slim 7 14ILL11 decks and side ports; the MacBook and UX3405CA use separately identified references. Port offsets and contours remain estimates, with uncertainties shown in the source notes. The 83JY AMD Slim has manufacturer dimensions and port inventory, with unpositioned ports because the supplied Slim video shows a different chassis.
- Photo-traced MSI and English/Arabic MacBook keyboard layouts, with source overlays. Other regional key legends remain unverified.
- Owner reports retain configuration and test differences. Reported battery hours are approximate inputs to the score when every eligible laptop has a value. Missing data is explicit.
- Preferences, prices, stock, sound ratings, pad measurements and calibration persist in this browser only. No server database.

This is a public source snapshot. Private conversation links and hosting identifiers are omitted. The MSI battery figures are a user-supplied example. Manufacturer and user-supplied reference images retain their original ownership; no ownership or license to those images is claimed. See [RESEARCH.md](RESEARCH.md) for the 7 October 2026 audit, sources and remaining physical uncertainties.

Validation: JavaScript syntax and browser interaction checks for selection, catalog groups, comparison views, ranking, availability and physical calibration; desktop and phone-width layouts checked in a browser.
