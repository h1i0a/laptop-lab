# Laptop Lab

Static laptop comparison website for GitHub Pages. No install, backend or build required.

Publish main / (root) in Settings → Pages. All app files are at repository root.

- Compare up to four devices with SAR prices, editable availability and weighted scores.
- Category leaders for battery, CPU, display and weight; sound uses personal listening ratings.
- Physical design inspector with closed sides, front/rear, lid, display lip, deck and touchpad. Calibrate against a 100 mm ruler for 1:1 physical display on your current screen. Contours are illustrative; this is not CAD or a mechanically exact trace.
- Photo-traced MSI and English/Arabic MacBook keyboard layouts, with source overlays.
- Owner reports retain configuration and test-method differences. Missing data is explicit.
- Preferences, prices, stock, sound ratings, pad measurements and calibration persist in this browser only. No server database.

This is a public source snapshot. Private conversation links and hosting identifiers are omitted. The MSI battery figures are a user-supplied example. Manufacturer and user-supplied reference images retain their original ownership; no ownership or license to those images is claimed.

Validation: DOM interaction checks for comparison, recommendations, availability, category leaders, all inspector views, physical scale, measurements and resets. A full browser layout check was unavailable in the editing environment.
